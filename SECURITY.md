# Security Policy

FlowRoute is unaudited, testnet-only software. Do not use it with real funds on Stellar mainnet without a professional security audit of both this repository and the [flowroute-contract](https://github.com/Stellar-flowroute/flowroute-contract) repository.

## Scope

This policy covers:

- `packages/sdk`
- `apps/web`
- `indexer`

The on-chain contract itself is out of scope here; report contract-level issues against [flowroute-contract](https://github.com/Stellar-flowroute/flowroute-contract) instead.

## Reporting a vulnerability

If you find a security issue, do not open a public GitHub issue. Instead, contact [@Hollujay](https://github.com/Hollujay) directly, for example through a GitHub private security advisory on this repository.

Please include:

- A description of the issue and its potential impact.
- Steps to reproduce, or a proof of concept if available.
- Any relevant logs, transaction hashes, or ledger references.

We will acknowledge reports as soon as possible and work with you on a fix before any public disclosure.
